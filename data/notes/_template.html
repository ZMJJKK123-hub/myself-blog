正文随便写

这是手写 HTML 笔记模板：上面 <!-- --> 注释里是元数据（title / category / date 必填）， 注释结束后整段就是你自己的 HTML，原样渲染，不会转义。

常用标签：加粗、斜体、链接、 行内代码、删除线。

  • 列表项
  • 列表项

引用块，样式跟着整站走。

// 围栏代码块渲染后右下角会有复制按钮
const answer = 42;

也可以放表格、图片（图片要先放进 data/media/ 以 /media/xxx.webp 引用）、 甚至内嵌 <style> 写一点笔记专属样式。

使用方法：复制本文件 → 改名（小写字母数字短横线，如 my-first-note.html）→ 改元数据 → 写正文 → 保存刷新即发布。category 写任何新类别都会自动出现在筛选栏。 下划线开头的文件不会被网站读取，可以当草稿。
