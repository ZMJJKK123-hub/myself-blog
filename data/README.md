# data — 网站内容都在这里

改完保存，刷新页面即可生效（后端每次请求都重新读取这里，不用重启服务）。
如果页面提示「内容暂时不可用」，说明某个文件格式写错了，
具体是哪个文件、哪一行，看 `npm run dev` 的控制台输出。

## 目录结构

| 位置 | 内容 | 怎么改 |
| --- | --- | --- |
| `profile.json` | 关于我页 + 首页自我介绍 | 直接编辑 |
| `projects/<slug>.json` | 项目档案，一个文件一个项目 | 复制 `_template.json` 改名（文件名必须等于里面的 `slug`）；`order` 数字控制展示顺序，越小越靠前 |
| `notes/<slug>.md` | 学习笔记，一篇一个 Markdown 文件 | 复制 `_template.md` 改名（文件名就是网址） |
| `life.json` | 校园与生活页的文字和照片清单 | 直接编辑 |
| `media/*.webp` | 照片文件 | 放文件 + 在 `life.json` 登记（见 `media/README.txt`） |

下划线（`_`）开头的文件会被网站跳过，可以作为模板或草稿保留。

## 分类是自由的

笔记、项目、照片的 `category` 都不需要在任何地方预先注册：

- 笔记头部信息里写 `category: 量子计算` → 笔记页筛选栏自动出现「量子计算」按钮
- 项目 JSON 里写 `"category": "游戏开发"` → 项目页筛选栏自动出现
- 照片在 `life.json` 里写 `"category": "羽毛球"` → 生活页筛选栏自动出现

只有 `status`（项目状态）仍是固定三选一：`持续开发` / `已有实现` / `早期作品`。

## 常见格式错误

- 笔记缺少 `---` 头部信息，或头部缺 `title` / `category` / `date`
- 笔记正文用了 `# ` 一级标题（正文标题请用 `## `）
- 项目文件名和 JSON 里的 `slug` 不一致
- `repositoryUrl` 不是 https:// 开头（没有就写 `null`）
- 日期不是 `YYYY-MM-DD` 格式
- 文件名包含大写字母、中文或下划线（slug 只允许小写字母、数字、短横线）

每个文件夹里都有示例文件，照着抄最稳妥。
